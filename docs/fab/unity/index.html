Unity Integration Guide

Workflows for Universal Render Pipeline (URP), High Definition Render Pipeline (HDRP), and PBR material setup in Unity 2022 / 2023 LTS.

1. Render Pipeline Compatibility

Our asset packages are delivered with industry-standard metallic/roughness PBR textures, making them 100% compatible with:

  • Universal Render Pipeline (URP): Lit & Complex Lit shaders.
  • High Definition Render Pipeline (HDRP): Lit shader with Subsurface Scattering and Coat map support.

2. Texture Channel Packing in Unity

Our textures use the industry-standard ORM (Occlusion, Roughness, Metallic) packing format:

ORM Channel Map Allocation 
Red Channel   (R) : Ambient Occlusion (AO)
Green Channel (G) : Roughness (Inverted for Smoothness if required)
Blue Channel  (B) : Metallic Mask
Alpha Channel (A) : Optional Height / Opacity

3. Prefabs & LOD Groups

Imported FBX models include embedded hierarchical LODs (LOD0 through LOD3) and custom convex collision meshes. Drag and drop prefabricated variants directly into your Unity scene hierarchies.

Normal Map Color Space

Ensure that all Normal map textures have Texture Type: Normal map selected in the Unity Inspector to prevent lighting artifacts.
