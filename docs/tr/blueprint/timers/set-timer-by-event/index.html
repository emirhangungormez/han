Set Timer by Event (Olay Zamanlayıcısı)

Unreal Engine oyunlarında Event Tick maliyetini düşürmek ve belirli zaman aralıklarında (örneğin 0.5 saniyede bir can yenileme, 1.0 saniyede bir yapay zeka alan taraması) fonksiyon çalıştırmak için en çok tercih edilen optimizasyon node'udur.

Kategori: Timers & Async Zorluk: Orta FTimerManager::SetTimer

İnteraktif Blueprint Grafiği

Pin Parametreleri

  • Delegate (Kırmızı Halka): Tetiklenecek Custom Event'in solundaki kırmızı delegate pinine bağlanır.
  • Time (Float): Timer'ın kaç saniye sonra çalışacağını belirler (Örn: 1.0).
  • Looping (Bool): Eğer True ise işlem her belirtilen sürede tekrarlanır. False ise sadece bir defa çalışır ve durur.
  • Return Value (Timer Handle): İleride zamanlayıcıyı durdurmak veya sıfırlamak (Clear and Invalidate Timer by Handle) için saklanması gereken referanstır.
Neden Event Tick Yerine Timer Kullanmalısınız?

Event Tick saniyede 60-144 kez çalışır ve oyunun CPU çerçeve süresini (frame-time) tüketir. Bir can yenileme veya harita tarama işlemi saniyede 1 kez çalıştığında oyuncu aynı deneyimi yaşar ancak işlemci yükü %98 oranında azalır.
