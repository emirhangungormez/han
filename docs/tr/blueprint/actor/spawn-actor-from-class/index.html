SpawnActorFromClass (Dinamik Aktör Üretimi)

Oyun çalışırken (runtime) hafızadan yeni bir Aktör sınıfı örneği (örneğin mermi, düşman yapay zekası, ganimet kutusu veya partikül taşıyıcı) türetip belirtilen 3D Transform koordinatında dünyaya yerleştirir.

Kategori: Actor Management Zorluk: Orta UWorld::SpawnActor

İnteraktif Blueprint Grafiği

Önemli Ayarlar & Gotchas

  • Class (Mor Pin): Dünyaya oluşturulacak Blueprint sınıfı (Örn: BP_Projectile, BP_EnemyGoblin).
  • Spawn Transform (Turuncu Pin): Konum (Location), Açı (Rotation) ve Ölçek (Scale) bilgilerini içeren FTransform yapısı.
  • Collision Handling Override: Oluşturulacak yer başka bir nesneyle çakışıyorsa ne yapılacağını belirler (Always Spawn, Ignore Collisions veya Try To Adjust Location, But Always Spawn).
  • Return Value (Mavi Pin): Üretilen aktörün referansıdır. Üretim başarısız olduysa Null dönecektir. Üretim sonrası değişkene kaydedilmelidir.
