Support Request Guidelines

To help us resolve technical questions quickly, please include the following details in your email:

  • Product Name: The exact asset pack or package name from Fab.
  • Engine Version: e.g., Unreal Engine 5.3, 5.4, 5.5, or Unity 2022/2023 LTS.
  • Render Pipeline: Lumen + Nanite (Default), Forward+, Deferred, URP, or HDRP.
  • Issue Description: Steps to reproduce, screenshot or video recording if applicable.
